# templates/

User-provided empty Kdenlive project templates live here. `studio scaffold`
injects clips into a copy of one of these files; it never generates a
`.kdenlive` from scratch.

Create one per Kdenlive version you use, named `empty-<ver>.kdenlive` (e.g.
`empty-25.12.kdenlive`). See the README's "Kdenlive template setup" section for
the one-time procedure (create empty project → add bin folders `A-Cam`,
`B-Roll`, `Audio`, `Selects` → save here).
